Controller poll (ROM mode CTRL_POLL)

Select CTRL_POLL from the ROM MODE MENU. Host sends REQ_CONTROLLER at the interval below; on the N64 hold L+R ~5s to return to the MODE MENU (ROM sends M64T 0xF1).

Listen (inbound L3 / M64T)

Stop multi64d (and any app using the cart serial port). These tools open the USB serial link directly — they cannot run while multi64d holds the same port. ROM must be in RAW_ECHO (mode 0).

Binaries are loaded from the workspace target/release or target/debug: cargo build -p sc64-echo-test and cargo build -p sc64-l3-framing-e2e.

sc64-echo-test

Raw L3 octet loopback (no M64B framing).

sc64-l3-framing-e2e

Full L3 wire frames echoed verbatim; optional large multi-chunk case.

multi64d must be running. Load multi64_test.z64 and choose RAW_ECHO (mode 0) in the ROM menu. Sends WebSocket binary frames; the cart echoes raw L3 bytes (same as scripts/multi64_ws_test.py --skip-http --assert-echo style check).

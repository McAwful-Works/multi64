        Adding the agent

        Archipelago patches a seed for your game. That seed knows how to play your slot, but not how to reach a real console — the agent is the piece that does, and AP64 writes it into a copy of the seed.

        1. Generate and patch your seed with Archipelago as usual.
        2. Drop the .z64 here, or use Browse….
        3. AP64 checks the seed is one it knows, then Add agent… writes a new file beside it ending -agent.z64. Your original seed is left alone.
        4. Load that new file on the console, then come back to Play.

        If a seed is refused, the checks in the patch window say which one failed. The usual cause is a game or a release AP64 has no profile for.

        Playing

        1. Plug the cart in and start the Multi64 app. AP64 starts it for you if it is not already running.
        2. Load the ROM with the agent on the console and let it run. AP64 reads it from the cart, so there is no file to choose here.
        3. Press Start.
        4. Open the game's client from the Archipelago Launcher and connect it to your room.

        The three rows say which part is up: Multi64 is the bridge to the cart, Console is the ROM answering, and Client is the Archipelago client connected to AP64.

        Start keeps trying until you press Stop. Resetting the console, swapping the ROM or restarting Multi64 will not end a session — it waits, and picks up where it left off.

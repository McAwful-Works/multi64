          Adding the agent

          Archipelago patches a seed for your game. That seed knows how to play your slot, but not how to reach a real console — the agent is the piece that does, and AP64 writes it into a copy of the seed.

          1. Generate and patch your seed with Archipelago as usual.
          2. Drop the .z64 here, or use Browse….
          3. AP64 checks the seed is one it knows, then Add agent… writes a new file beside it ending -agent.z64. Your original seed is left alone.
          4. Load that new file on the console, then come back to Play.

          If a seed is refused, the checks in the patch window say which one failed. The usual cause is a game or a release AP64 has no profile for.

          Playing

          1. Plug the cart in and start the Multi64 app, which is installed separately. AP64 starts it for you if it is installed and not already running.
          2. Load the ROM with the agent on the console and let it run. AP64 reads it from the cart, so there is no file to choose here. The console needs an Expansion Pak: the agent runs in its memory, and without one it never starts, so AP64 waits with nothing to tell it why.
          3. Press Start.
          4. Open the AP client from the Archipelago Launcher and connect it to your room.

          The three rows say which part is up: Multi64 is the bridge to the cart, Console is the ROM answering, and AP client is the game's Archipelago client connected to AP64.

          Start keeps trying until you press Stop. Resetting the console, swapping the ROM or restarting Multi64 will not end a session — it waits, and picks up where it left off.

          Before you play

            Before you start

            To play Archipelago on a real N64, AP64 needs:

            • An N64 with an Expansion Pak. AP64's agent runs in its memory, and without one it never starts.
            • A SummerCart64, connected to this PC by USB. EverDrive-64 X7 and PRO support is experimental: AP64 can build the agent for them, but it has never been shown to work on either.
            • The Multi64 app, the bridge to the cart. It has its own installer, from the same place as AP64's, and once it is installed AP64 starts it when you press Start.
            • Archipelago, with your game's world installed, and a seed it patched for you.

            Supported games

              Patch your seed with Archipelago as usual, then bring it here. The release each profile expects is the one Archipelago patches, so there is nothing to choose.

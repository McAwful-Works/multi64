Xfer64

A Multi64 product — separate app: two-pane file manager for SC64 SD (USB mass storage) ↔ Windows. The button runs the bundled installer when Xfer64 is not installed, or opens it when it is.

Developer

Integrations (Archipelago, etc.) should use the daemon WebSocket — same contract as docs/spec/daemon-api-v1.md in the repo.

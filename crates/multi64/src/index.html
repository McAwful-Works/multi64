What Multi64 does

            

              Multi64 runs the bridge (multi64d) between a USB flash cart and tools on this PC. Tools
              connect to the bridge over a local HTTP + WebSocket address, set under Settings → Listen.
            

            

              Only one program can use the cart's serial port at a time. Xfer64 pauses the bridge while it works
              with the cart and resumes it afterward.
            

          


          

            
Carts

            

              With Cart on Auto-detect, Multi64 looks for a SummerCart64 by its USB IDs, without
              sending anything to the cart. If none is found, Start bridge sends cart test commands
              to the serial port — or to each serial port, when Serial port is on Auto-detect — until a cart
              answers.
            

            

              SummerCart64 is the proven cart. The EverDrive-64 X7 and EverDrive-64 PRO are experimental: neither
              has been tested on a real cart.
            

          


          

            
Starting and stopping

            

              Start bridge and Stop bridge on the Status card start and stop the
              bridge. To start it whenever Multi64 opens, turn on
              Start the bridge when Multi64 opens in Settings.
            

            

              With the notification area (system tray) turned on, closing the window can hide Multi64 there instead
              of exiting. Open it again, or start, stop and restart the bridge, from the tray icon.
            

          


          

            
Xfer64

            

              Xfer64 is a separate app that copies files between the cart's SD card and This PC over USB. The
              Xfer64 card installs it, or opens it once it is installed.

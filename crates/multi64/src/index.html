What Multi64 does

            

              Multi64 runs multi64d, a bridge between a USB flash cart and tools on this PC. Tools
              connect to it over a local HTTP + WebSocket address, set under Settings → Listen.
            

            

              Only one program can use the cart's COM port at a time. Xfer64 pauses the bridge while it works with
              the cart and resumes it afterwards.
            

          


          

            
Carts

            

              With Cart on Auto-detect, Multi64 looks for a SummerCart64 by its USB IDs, without
              sending anything to the cart. If none is found, Start daemon sends cart test commands
              to the COM port — or to each serial port, when COM port is on Auto — until a cart answers.
            

            

              SummerCart64 is the proven cart. The EverDrive-64 X7 and PRO are experimental: neither has been
              tested on a real cart.
            

          


          

            
Starting and stopping

            

              Start daemon and Stop daemon on the Status card control
              multi64d. To start it whenever the app opens, turn on
              Start multi64d automatically when this app opens in Settings.
            

            

              With the notification area (system tray) turned on, closing the window can hide Multi64 there instead
              of exiting. Open it again, or start and stop the daemon, from the tray icon.
            

          


          

            
Xfer64

            

              Xfer64 is a separate app for copying files between the cart's SD card and Windows. The Xfer64 card
              installs it, or opens it once it is installed.

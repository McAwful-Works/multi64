Help

Flash cart & USB

SummerCart64 and EverDrive 64 X7 connect over USB using a COM port—not like a USB thumb drive (there is no new drive letter in Windows). Xfer64 opens that port only while it lists or copies files, then lets it go. If something else is using the same port (for example the Multi64 app talking to the cart), close it first or you may see “port busy” errors.

Auto-detect

In Settings, Auto-detect (recommended) tries to figure out which cart is plugged in. If it guesses wrong, pick SummerCart64 or EverDrive-64 X7 (beta) yourself.

EverDrive (beta)

EverDrive talks to the PC differently than SummerCart64. If you pick EverDrive in Settings and want to browse the SD card from this app, use EverDrive (advanced) there and enter the value your setup needs (or leave it blank if you only need the serial port for other tools). For the simplest “plug in and go” SD access from Windows here, choose SummerCart64 or Auto-detect when a SummerCart64 is connected.

Technical details

Access uses the vendor serial protocol and an optional linear ROM base address; firmware-dependent, and some card operations may be read-only. Repository documentation under docs/spec/ has the full picture for developers.

Tips

If the SD card is write-protected, turn the N64 off before changing files on some carts. The right pane is a normal Windows folder.

Xfer64

by Multi64

—

Copy and manage files between your flash cart’s SD card and a folder on Windows. USB is only used while listing or transferring.

Settings

Cart device

EverDrive (advanced)

Optional. Needed only if you want to list and copy files on the SD card from this PC while EverDrive-64 X7 (beta) is selected above.

For advanced users: firmware-specific address for SD access over USB. Wrong values will not work. Clear the field to turn off SD browsing from this app. Use Scan for SD base to guess a value from the card (takes a short while).

Windows integration

Add Xfer64 upload to your user Send to menu (right-click a file → Send to). A small window opens so you can pick the SD folder before uploading—nothing runs in the background.

Developer

When enabled, the backend records serial session open/close and cart operations. Use the log window to watch in real time (similar to Multi64 GUI developer mode).

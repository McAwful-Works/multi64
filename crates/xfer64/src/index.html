Flash cart & USB

The SummerCart64, EverDrive-64 X7 and EverDrive-64 PRO connect over USB using a serial port — not like a USB thumb drive (there is no new drive letter in Windows). Xfer64 opens that port only while it lists or copies files, then lets it go. The Multi64 bridge (multi64d) is paused while Xfer64 uses the cart and resumes afterward. If another app is using the same port, close it first or you may see "port busy" errors.

Auto-detect

In Settings, Auto-detect (recommended) tries to figure out which cart is plugged in. If it guesses wrong, pick SummerCart64, EverDrive-64 PRO (experimental) or EverDrive-64 X7 (experimental) yourself.

EverDrive-64 PRO (experimental)

The EverDrive-64 PRO serves its SD card to This PC directly, so Xfer64 can browse it, copy files both ways, create folders and delete. Support is ported from Krikzz's published sources and has never been tested on a real cart, so Xfer64 asks before the first write each time it runs. The EverDrive-64 PRO's USB link has no rename command, so renaming copies the item to its new name through This PC and then deletes the original. That takes as long as copying it off the cart and back, and cannot change only the letter case of a name.

EverDrive-64 X7 (experimental)

The EverDrive-64 X7 talks to This PC differently than the SummerCart64. Browsing its SD card from Xfer64 is experimental: its USB protocol has no SD command, so Xfer64 reads cart memory instead, and that is not expected to show your card's files. The settings are under EverDrive SD (experimental); leave the address blank if you only need the serial port for other tools. For SD card access over USB, use a SummerCart64, or Auto-detect with one connected.

Technical details

Experimental and read-only. Xfer64 sends the vendor RomRead command at a linear base address, which reads cart ROM memory rather than the SD card, so no address is expected to list the card. docs/spec/ed64-sd-usb-host.md in the repository explains why.

Tips

If the SD card is write-protected, turn the N64 off before changing files on some carts. The right pane, This PC, is a normal folder on your computer.

Xfer64

by Multi64

—

Copy and manage files between your flash cart's SD card and a folder on This PC. USB is only used while listing or transferring.

Settings

Appearance

Applies immediately. Not part of Save settings.

Cart device

EverDrive SD (experimental)

Experimental and read-only. Xfer64 reads cart memory here rather than the SD card, so this is not expected to list your card's files. Used only while EverDrive-64 X7 (experimental) is selected above.

Experimental: the address is read with the vendor RomRead command, which reaches cart memory rather than the SD card, so no value is expected to show your card. Clear the field to turn this off. Scan for SD base looks for memory that resembles a disk (takes a short while).

Scanning runs immediately; the address is saved with Save settings.

Windows integration

Acts immediately. Not part of Save settings.

Add Quick upload to your user Send to menu (right-click a file → Send to → Xfer64 upload). A small window opens so you can pick the cart folder before uploading — nothing runs in the background.

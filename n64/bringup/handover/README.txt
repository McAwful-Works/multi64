Multi64 cart diagnostics
========================

1. Copy multi64_test.z64 and multi64_bringup.z64 to your cart's SD card.
2. Connect the cart to this PC by USB and turn the console on.
3. Close Multi64, AP64 and Xfer64 if they are open.
4. Double-click diagnose.bat and follow what it says.
5. Send back the zip file it makes.

If Windows warns about the files, choose "More info", then "Run anyway".

If it asks for a COM port, Device Manager lists it under "Ports (COM & LPT)".

Multi64_..._setup.exe is the latest Multi64. You don't need it for the test.
